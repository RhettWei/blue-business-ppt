# 视觉规范

以下数值是针对用户样图形成的实现约定，代表色采用人工视觉归纳。用户已有主题时沿用其要求。

## 配色

| 用途 | 色值 | 使用方法 |
|---|---|---|
| 蓝色主系列 | `#5E86A6` | 折线、分布轮廓、关注组 |
| 浅蓝填充 | `#D6E4EE` | 置信带、背景区域、浅柱体 |
| 金色对照 | `#D4A14C` | 对照系列、尾部区域、参考值另一侧 |
| 浅金填充 | `#FAE7BE` | 分布填充、阈值区域 |
| 鼠尾草绿 | `#91AF96` | 第三组、第二个检验面板 |
| 浅绿填充 | `#DEEADD` | 辅助分布和第三组填充 |
| 深蓝 | `#183C55` | 观测值、均值、重点参考线 |
| 正文 | `#202830` | 标题、轴标签、重要标注 |
| 次要文字 | `#59636C` | 来源、图注、次要刻度 |
| 灰色背景系列 | `#B9BEC2` | 多条系数路径和背景基准 |
| 网格 | `#E4E8EB` | 轻虚线，避免抢占数据 |

金色细线和文本使用较深的 `#997025`。浅填充配深轮廓或深标签。颜色之外增加线型、点形、图例或直接标签。

## 字体与尺寸

英文优先 Arial，中文依次匹配 Microsoft YaHei、Noto Sans CJK SC、SimHei 等系统字体。模块自动选择可用字体。出现中文缺字警告时安装或指定中文字体后重新生成。

| 元素 | 约定 |
|---|---|
| 单图宽高 | 通常 9 × 5.5 英寸，按标签数量调整 |
| 双面板宽高 | 通常 12.8 × 6.0 英寸 |
| 图标题 | 16–18 pt，正文色，中等字重 |
| 面板标题 | 12–14 pt，左对齐，A / B 标记 |
| 轴标题 | 11–12 pt，包含单位 |
| 刻度与图例 | 10–11 pt |
| 来源与说明 | 9–10 pt，保证最终显示可读 |
| 主线 | 1.5–2.0 pt |
| 次要线 | 0.6–0.9 pt |
| 坐标轴 | 左与下边框，0.7 pt |

SVG 和 PDF 用于缩放与排版，PNG 用于直接预览。导出用 `bbox_inches=None` 保留设定的画布尺寸，在布局中为文字预留空间。

## 布局和标注

默认白底。数值轴可使用浅灰虚线网格。零值、观测值、阈值和基准线根据分析问题添加。

分布透明度通常 0.35–0.65，密集散点通常 0.15–0.30。误差条比均值线更浅，重要观测线用深蓝。

图例通常放在图下方，采用水平排列和无边框。少量曲线优先末端标签。预留标注区，调整轴范围时保留真实坐标关系。

来源与数据口径放在底部预留区。长来源换行或放入相邻图注文件，按最终页面宽度检查。

同一报告中的同一指标保持同一单位、颜色和基准。蓝金分组的含义应由图例说明。使用财经涨跌色时遵循市场和读者习惯。
