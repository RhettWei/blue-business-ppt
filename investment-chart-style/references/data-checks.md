# 数值和口径检查

## 数据准备

记录来源文件或来源链接、数据期、检索时间、单位、样本范围、筛选与聚合方法。用到的列分别处理缺失，避免其他无关列导致观测被删。存在重复、异常值或口径变化时，先确定处理方式并在代码中保留。

## 投研口径

| 场景 | 核对项目 |
|---|---|
| 股价与收益 | 前复权 / 后复权 / 不复权，含息与否，币种，交易日频率，区间起止 |
| 净值比较 | 同一起点归一化，基准，费前 / 费后，累计收益与年化收益 |
| 财务指标 | 合并 / 母公司，TTM / 单季 / 累计，会计期，金额单位 |
| 估值 | PE / PB / EV 倍数定义，静态 / TTM / 预测，负盈利处理，样本权重 |
| 预测与情景 | 实际值与预测值的分界，情景条件，区间含义，预测日期 |
| 统计区间 | SD / SE / CI 的类型，样本量，观测单位，重复测量或时间依赖 |

## 模型路径

参数的数值、排序和坐标标签来自同一数组。`λ` 为惩罚强度时，较大值对应更强惩罚。单个系数可以非单调变化，总体路径需与拟合器一致。`C` 等反惩罚参数按其文档处理。

`λ₁se` 按适用的一标准误差规则选择较大 λ，验证目标是最小化损失还是最大化分数要明确。路径、参数选择、关注因子标注都从同一次拟合结果计算。

## 三元图

检查数值有限、非负、每行总和为 1。重归一化由明确参数触发，零和行应报告。区域划分从公式推导，边界、点颜色与图例采用同一条件。边际图使用相同样本和变换。

## 置换检验

观测统计量和置换统计量采用同一定义。p 值记录尾部、Monte Carlo 或精确枚举方法，以及是否使用加一校正。控制随机种子，时间序列使用研究设计所需的置换单位。密度曲线与柱体用于展示，不参与尾部计数。

## 导出检查

查看 PNG，并核对同次导出的 SVG 与 PDF 是否存在、尺寸正确、文字完整。用最终展示尺寸判断字号。检查超长标题、长中文分类名、负值、零参考值、全常量组和缺失数据在当前图中的实际效果。

`scripts/check_exports.py` 检查文件存在、PNG 内容及 SVG / PDF 结构，生成 JSON 报告。其自动结果覆盖文件层面的检查，数值与布局还需结合数据和预览核对。

每次导出的 JSON 还包含 `layout`，记录文本裁切、小字号、文本碰撞候选和字体。碰撞候选需结合图形判断，例如有意放在标注框中的文字与其他文字的实际关系。绘图入口共享主题，颜色调整在 `chart_style.py` 集中进行。
