# 图形模板

按当前问题读取对应部分。数据可从 CSV、Excel、研究结果文件或数据库取得，聚合和统计计算保存在生成脚本中。

## 基础六类 JSON 入口

完整的 30 类目录见 [coverage.md](coverage.md)，新增模板的数据字段见 [extended-patterns.md](extended-patterns.md)。本页保留六类基础入口和参考图组合方法。

所有规格包含 `type`、`title`、`data`。可设置 `source`、`note`、`xlabel`、`ylabel`、`unit`、`reference`、`figsize`。日期作为有序字符串输入时保留给定顺序，时间线应先按日期排序。示例文件中的数据明确标为模拟。

| 类型 | `data` 字段 | 可选字段 |
|---|---|---|
| `line` | `x`，`series`，每组含 `name` 和 `y` | 每组可含 `lower`、`upper` |
| `ranked` | `labels`，`values` | `lower`、`upper`，表示区间端点 |
| `violin` | `labels`，`groups`，每组为原始观测数组 | `sort` 默认 true |
| `permutation` | `null_values`，`observed` | `side` 为 right / left，`bins` 默认 30 |
| `ternary` | `probabilities`，三列为顶点、左下、右下 | `labels`，`normalize` 默认 false |
| `heatmap` | `matrix`，`row_labels`，`column_labels` | `center`，`vmin`，`vmax` |

`reference` 缺省时，排序图和分布图使用零参考值，折线图根据数据本身绘制。`unit` 为值标签的后缀。百分数在输入前明确采用 0–1 还是 0–100。

## 系数路径与交叉验证，对应参考图 2

采用两个面板。左侧多条系数路径，大部分灰化，关注因子用蓝金区分，右端附近直接标注因子名称。右侧显示交叉验证均值、误差条和置信带。两侧使用同一参数变换与方向。

从模型拟合对象取得系数、参数序列、非零系数个数及验证分数。`lambda_min` 采用最优分数对应的参数。最大化指标的一标准误差规则采用最优均值减去其 SE 作为阈值，在可接受参数中选择最大的 λ。

把选择结果传给两侧参考线，并计算对应的数值标注。横轴为递增 `log(λ)` 时，惩罚强度递增。拟合器以 `C` 表示反惩罚强度时，按其定义转换并标注。

随附 `render_gallery.py` 展示布局和参数方向。真实拟合应采用原始模型结果。

## 小提琴与箱线图，对应参考图 4

使用 `plot_violin`。按组均值排序，浅蓝和浅金区分均值在参考值两侧的组。白色箱体显示四分位距，深色短线显示中位数，菱形显示均值。小样本和常量组用观测标记或箱体表达。

投研可用于行业估值、基金收益、因子分组或不同市场的分布。估值负值、极端值及样本筛选口径需要在图注中交代。时间上重复观测的样本依赖性影响统计推断，绘图保留实际观测结构。

## 置换分布，对应参考图 5

使用 `plot_tail_distribution`。主体为直方图与核密度曲线，深蓝竖线显示观测统计量，金色高亮检验方向的尾部。

入口接收已计算的置换统计量，按 `(1 + 尾部样本数) / (B + 1)` 计算 Monte Carlo p 值。`side=right` 为大于等于观测值，`side=left` 为小于等于观测值。双侧检验应另写符合研究设计的统计定义。精确枚举或已有正式检验结果按其方法计算。

绘制的密度曲线仅用于展示形状，p 值依据置换样本计数。区块或分组置换的生成过程应体现时间序列与面板依赖。

## 三元概率与边际分布，对应参考图 3

使用 `plot_ternary`，顶点顺序为顶部、左下、右下。普通三元图每行三项之和为 1。另有未展示类别时，可在任务允许的情况下用 `normalize=true` 对展示分量重归一化，图注记录原公式与处理。

若展示分量为 `q`，`q_left + q_right = q_top` 等价于 `q_top=0.5`，边界平行底边。模板按这个等式绘制区域。真实业务采用不同权重时从业务公式推导边界。

边际分布与三元图使用同一处理后的样本，均值由数组计算。图中的上半区和下半区用数值条件命名，投资含义由研究情境决定。

## 常用投研图

- 营收、利润和资产走势使用 `plot_lines`。折线遇缺失值保留间断，预测区间用同色浅填充，预测起点用参考线和明确标签。
- 同行比较、估值区间和目标价区间使用 `plot_ranked`。统一口径、比较基准和单位，横向排序，区间采用实际上下端点。
- 因子相关性使用 `plot_heatmap`。相关系数固定到 -1 至 1，零点居中。缺失单元格用灰色，较多单元格按尺寸决定数值标签。
- 收入桥、利润桥和瀑布图可用 Matplotlib 直接实现，累计值从各项变动计算，正负颜色与公司及市场习惯一致。
